🔒 强制模式

📚 学习联动

目标没打完就继续屏蔽 来自 WorkBuddy 学习台
过了今天的屏蔽时段，如果学习台里今天的目标还有没打卡的，就一直屏蔽，直到打完为止（没有结束时间）。 开关可随时关闭；关闭后会立即解除由学习联动产生的延长屏蔽。 另外每天 20:00 判断一次：这时还没打卡完成（或 20:00 之后才补上最后一笔），当天屏蔽结束点就再延 30 分钟 （例如 21:00 放行 → 21:30 才放行），一天只记一次，补打卡也不撤销。 读不到学习进度（WorkBuddy 没开 / 数据超过 45 分钟没更新）时会正常解锁，不会把你锁死。

白名单
永远放行的域名与进程，优先于所有屏蔽规则，重要工作不会被误伤。

🛡 白名单域名

白名单优先于屏蔽。两种写法:
· 纯域名 mail.example.com — 整站放行(即使被屏蔽)
· 域名+路径 www.bilibili.com/video/* — 只放行该路径, 同域名的其他页面仍按屏蔽表处置
路径放行依赖浏览器 URLBlocklist/URLAllowlist(需开启「网址拦截」并重启浏览器生效); hosts 层面仍是整站封。
强制模式开启期间白名单不可增删;需调整时请先在调整时段关闭强制模式。

🛡 白名单进程

即使出现在屏蔽列表里,这些进程也永远不会被结束(支持通配符)。
强制模式开启期间白名单不可增删;需调整时请先在调整时段关闭强制模式。

工作原理(点击展开)
  • 网站屏蔽: 屏蔽期间向 hosts 文件写入 0.0.0.0 域名 记录,浏览器无法解析这些域名;解除时自动清除,只删除本程序写入的行,不动你的其他配置。
  • 进程屏蔽: 强制结束匹配的进程,每分钟复查一次。
  • 计划任务: 安装时注册 "AwayFromShorts" 任务,每分钟运行一次屏蔽引擎(需要管理员权限写 hosts)。
  • 本配置面板只是本地网页(127.0.0.1),不会联网发送任何数据。

🗑 卸载

卸载会删除计划任务、恢复 hosts 文件(仅移除本程序写入的行)、删除程序目录。你的其他文件不受影响。
也可以手动运行 %LOCALAPPDATA%\AwayFromShorts\uninstall.bat(需管理员)。
